    Injury watch

    Built from the pain you report in each run's post-run check-in — there is nothing to record twice. A hard strength session in the two days before the pain first appeared is shown as a possible link, with the exercises that load the same muscles.

    Export for a coach or physiotherapist

    One page: totals, load, intensity distribution, injury episodes with the days before them, recent strength sessions and shoe mileage. Generated locally; nothing is uploaded.

    Drop files into the matching zone, or press Enter on a zone to choose them. Each folder only accepts the formats its importer understands, so a file cannot land somewhere nothing will read it. Files are written to data/; a file with the same name is replaced.
